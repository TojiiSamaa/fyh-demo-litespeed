# fyh-demo-litespeed

Site de test pour le panel ForYouHost : LiteSpeed — site vitrine statique « Café des Arts » (HTML/CSS).
Toutes les données sont fictives.

Dans le panel : Nouveau site → type correspondant → URL de ce dépôt, branche `main`.
Pour tester la mise à jour automatique, modifiez « v1 » dans la page et poussez : le site doit afficher la nouvelle version en une minute environ.
